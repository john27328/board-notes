# Примеры

*(English version: [examples.md](examples.md))*

Каждый пример идёт в одном порядке: **доска** → как выглядит → **шаблон карточки** → карточка из него. Подробнее про внешний вид: [Как это выглядит](appearance.ru.md).

## 1. Медиа-список (аниме, фильмы, книги)

### Доска

````markdown
```board
tag: "#anime"
folder: Anime
template: Templates/Anime.md
columns: [планы, смотрю, просмотрено]
meta: [Год, Оценка]
coverField: Обложка
exclude:
  - Templates/Anime.md
facets: [Жанры]
vocab:
  Жанры: [драма, комедия, фэнтези]
  Теги: [магия, космос]
card:
  fields: [Оценка, Описание, Рекомендация]
  ratingField: Оценка
  recField: Рекомендация
```
````

```text
┌────────────────────────────────────────────────────────────────┐
│ @  [Таблица] [Доска]  [ Поиск по всем полям карточки.  ] 3     │
│ Жанры - включать     [драма] [комедия] [фэнтези] [пусто]       │
│ Колонки              [планы] [смотрю] [просмотрено]            │
├──────────────────┬──────────────────┬──────────────────────────┤
│ планы         1  │ смотрю        1  │ просмотрено           1  │
│ ┌──────────────┐ │ ┌──────────────┐ │ ┌──────────────────────┐ │
│ │ [обложка]    │ │ │ [обложка]    │ │ │ [обложка]            │ │
│ │ Монстр       │ │ │ Фрирен       │ │ │ Ковбой Бибоп         │ │
│ │ 2004         │ │ │ 2023         │ │ │ 1998 - * 9           │ │
│ │ [драма]      │ │ │ [фэнтези]    │ │ │ [драма] [космос]     │ │
│ │ / жанры/теги │ │ │ / жанры/теги │ │ │ / жанры/теги         │ │
│ └──────────────┘ │ └──────────────┘ │ └──────────────────────┘ │
│ + добавить       │ + добавить       │ + добавить               │
└──────────────────┴──────────────────┴──────────────────────────┘
```

`facets` даёт ряд фильтра по жанрам, `vocab` ограничивает варианты в редакторе ✎, `coverField` (викилинк `[[image.png]]`) рисует обложку, `exclude` убирает шаблон с доски.

### Шаблон карточки — `Templates/Anime.md`

````markdown
---
Статус: планы
Год:
Оценка:
Обложка:
Жанры: []
Теги: []
Описание:
Рекомендация:
---
#anime

```card
```

```tags
```
````

Оба блока пустые намеренно: раскладка берётся из `card:` в доске.

### Получившаяся карточка

```text
┌────────────────────────────────────────────────────────┐
│ Аниме  #anime                                      @   │
│ [планы] [смотрю] [просмотрено]                         │
│ * 9                                                    │
│ Охотник за головами в космосе, джаз и меланхолия.      │
│ | Смотреть ради последней серии                        │
│ @ поля карточки                                        │
├────────────────────────────────────────────────────────┤
│ словарь: Аниме - по тегу #anime                        │
│ Жанры   [драма] [комедия] [фэнтези]                    │
│ Теги    [магия] [космос]                               │
└────────────────────────────────────────────────────────┘
```

## 2. Задачи с подзадачами и автоархивом

### Доска

````markdown
```board
tag: "#task"
folder: Tasks
template: Templates/Task.md
columns: [backlog, in progress, review, done, archive]
meta: [Id]
baseTaskField: BaseTask
autoArchive:
  source: done
  target: archive
  afterDays: 14
facets: [Метки]
vocab:
  Метки: [bug, feature]
card:
  fields: [Id, BaseTask, Описание]
  links:
    - field: Pyrus
      label: "Открыть в Pyrus ↗"
  labels:
    Id: ID
    BaseTask: Базовая задача
  copyFields: [Id]
```
````

```text
┌──────────────────────────────────────────────────────────────────────┐
│ @  [Таблица] [Доска]  [ Поиск.  ] 4   [Только базовые задачи]        │
│ Метки - включать     [bug] [feature] [пусто]                         │
├───────────────┬───────────────┬───────────────┬──────────────────────┤
│ backlog    1  │ in progress 1 │ review     0  │ done              2  │
│ ┌───────────┐ │ ┌───────────┐ │               │ ┌──────────────────┐ │
│ │ Релиз 1.2 │ │ │ Fix login │ │               │ │ Update docs      │ │
│ │ 1/3 готово│ │ │ Id 4812   │ │               │ │ Id 4790          │ │
│ │ Id 4800   │ │ │ [bug]     │ │               │ │ [feature]        │ │
│ │ / метки   │ │ │ / метки   │ │               │ └──────────────────┘ │
│ └───────────┘ │ └───────────┘ │               │                      │
│ + добавить    │ + добавить    │ + добавить    │ + добавить           │
└───────────────┴───────────────┴───────────────┴──────────────────────┘
```

У родителя («Релиз 1.2») виден бейдж прогресса. `done` и `archive` считаются завершёнными. Карточка из `done` уходит в `archive` через 14 дней после последней смены статуса.

### Шаблон карточки — `Templates/Task.md`

````markdown
---
Статус: backlog
Id:
Pyrus:
BaseTask:
Метки: []
Описание:
---
#task

```card
```

```tags
```
````

### Получившаяся карточка (родительская задача)

```text
┌────────────────────────────────────────────────────────┐
│ Задачи  #task                     @   + подзадача      │
│ [backlog] [in progress] [review] [done] [archive]      │
│ Открыть в Pyrus > # /                                  │
│ ID: 4800 #                                             │
│ Базовая задача: +                                      │
│ Описание: подготовить релиз                            │
│ ┌ Дочерние задачи ─────────────────────────── 1/3 ┐    │
│ │ Fix login                        [in progress]  │    │
│ │ Fix token refresh                [backlog]      │    │
│ │ Update docs                      [done]         │    │
│ └─────────────────────────────────────────────────┘    │
│ @ поля карточки                                        │
└────────────────────────────────────────────────────────┘
```

**+ подзадача** создаёт заметку из того же шаблона с `BaseTask: "[[Релиз 1.2]]"`, копирует остальные поля родителя (метки, ссылку Pyrus…) и открывает её в новой вкладке. В её карточке родитель показан кликабельной ссылкой в «Базовая задача».

## 3. Таблица

### Доска

````markdown
```board
tag: "#movie"
view: table
columns: [хочу, смотрел]
table:
  columns:
    - field: __title
      label: Название
    - field: Статус
    - field: Оценка
  sort:
    - field: Статус
      direction: asc
    - field: __modified
      direction: desc
```
````

```text
┌──────────────────────────────────────────────────────────────┐
│ @  [Таблица] [Доска]  [ Поиск.  ]                            │
├───────────────┬─────────────┬────────────────────────────────┤
│ Название      │ Статус ^    │ Оценка                         │
│ [Фильтр     ] │ [Фильтр   ] │ [Фильтр                      ] │
├───────────────┼─────────────┼────────────────────────────────┤
│ Дюна          │ хочу        │                                │
│ Начало        │ смотрел     │ 9                              │
└───────────────┴─────────────┴────────────────────────────────┘
```

### Шаблон карточки

Шаблон того же вида, что выше (frontmatter + пустой блок `card`). В таблице ячейку правят двойным кликом; в заметке — поле в её карточке.

## 4. Плоский справочник (без статусов)

### Доска

````markdown
```board
tag: "#faq"
flat: true
facets: [Тема]
```
````

```text
┌────────────────────────────────────────────────────────┐
│ @  [Таблица] [Карточки]  [ Поиск.  ] 6                 │
│ Тема - включать     [git] [docker] [obsidian]          │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                 │
│ │ Git: rebase│ │ Docker.  │ │ Vault.   │  .            │
│ └──────────┘ └──────────┘ └──────────┘                 │
│ + добавить                                             │
└────────────────────────────────────────────────────────┘
```

Все карточки попадают в одну фильтруемую сетку, без колонок.

### Шаблон карточки

````markdown
---
Тема: []
---
#faq
````

Блок `card` не нужен: это просто текст с темой.

## 5. Одна заметка со своей раскладкой

Обычно раскладка живёт в доске. Заметка может переопределить её собственным непустым блоком:

````markdown
```card
fields: [Оценка, Кинопоиск, Описание, Рекомендация]
ratingField: Оценка
recField: Рекомендация
links:
  - field: Кинопоиск
    label: "Открыть на Кинопоиске ↗"
```
````
