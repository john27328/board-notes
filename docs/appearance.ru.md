# Как это выглядит

*(English version: [appearance.md](appearance.md))*

Текстовые макеты того, что рисует плагин. Подписи — настоящие строки интерфейса; цвета и отступы зависят от темы Obsidian.

> В макетах `/` обозначает ✎ (правка), `*` — ★, `@` — ⚙, `#` — ⧉ (копировать), `^`/`v` — ↑/↓, `x` — ×, `|` — акцентную полосу: чистый ASCII не ломает рамки в любом шрифте.

## Доска

Конфиг:

```board
tag: "#task"
template: Templates/Task.md
columns: [бэклог, в работе, готово]
meta: [Id]
facets: [Метки]
vocab:
  Метки: [bug, feature]
```

Результат:

```text
┌──────────────────────────────────────────────────────────────────────┐
│ @  [Таблица] [Доска]  [ Поиск по всем полям карточки.   ] 12         │
│    [Только базовые задачи]                                           │
│ Теги - включать      [#urgent] [#infra]                      [x]     │
│ Метки - включать     [bug] [feature] [пусто]                 [x]     │
│ Колонки              [бэклог] [в работе] [готово]                    │
├───────────────────┬───────────────────┬──────────────────────────────┤
│ бэклог         3  │ в работе       2  │ готово                    7  │
│ ┌───────────────┐ │ ┌───────────────┐ │ ┌────────────────────────┐   │
│ │ Починить вход │ │ │ Релиз 1.2     │ │ │ Обновить доки          │   │
│ │ 1/3 готово    │ │ │ 2/2 готово    │ │ │ Id 4812                │   │
│ │ Id 4812       │ │ │ Id 4790       │ │ │ [feature]              │   │
│ │ [bug]         │ │ │ [feature]     │ │ │ / метки                │   │
│ │ / метки       │ │ │ / метки       │ │ └────────────────────────┘   │
│ └───────────────┘ │ └───────────────┘ │                              │
│ + добавить        │ + добавить        │ + добавить                   │
└───────────────────┴───────────────────┴──────────────────────────────┘
```

- **Тулбар:** ⚙ настройки, переключатель вида (**Таблица** / **Доска**), поиск со счётчиком (`найдено / всего` при поиске) и фильтр базовых задач.
- **Ряды фильтров:** теги, каждое поле из `facets` и **Колонки** (показать/скрыть колонки). Клик по названию ряда (`Метки · включать`) переключает его в режим исключения.
- **Заголовок колонки:** название статуса и число карточек. **+ добавить** создаёт карточку с этим статусом.
- Перетащи карточку в другую колонку — сменится её статус.

### Карточка на доске

Сверху вниз, каждая часть — только если есть данные:

```text
┌──────────────────────────┐
│ [обложка]                │  < coverField
│ Починить вход            │  < заголовок: nameField > Название > имя файла
│ 1/3 готово               │  < бейдж прогресса базовой задачи
│ Id 4812 - * 8            │  < поля из meta
│ [bug] [login]            │  < текущие значения словаря
│ / метки                  │  < открывает редактор словаря
└──────────────────────────┘
```

Клик по карточке открывает заметку. **✎ метки** раскрывает панель чипов для правки словарных полей, не выходя с доски.

## Таблица

```text
┌──────────────────────────────────────────────────────────────┐
│ @  [Таблица] [Доска]  [ Поиск.  ]                            │
├───────────────┬─────────────┬──────────┬─────────────────────┤
│ Название ^    │ Статус      │ Оценка   │ Метки               │
│ [Фильтр     ] │ [Фильтр   ] │ [Фильтр ]│ [Фильтр           ] │
├───────────────┼─────────────┼──────────┼─────────────────────┤
│ Починить вход │ бэклог      │ 8        │ bug                 │
│ Релиз 1.2     │ в работе    │          │ feature             │
└───────────────┴─────────────┴──────────┴─────────────────────┘
```

У каждого заголовка свой текстовый фильтр; клик по названию сортирует, перетаскивание меняет порядок колонок. Двойной клик по ячейке — редактирование, одиночный по названию — открыть заметку.

## Карточка в заметке (` ```card `)

Конфиг (один раз, в блоке доски):

```yaml
card:
  fields: [Id, BaseTask, Описание, Рекомендация]
  links:
    - field: Pyrus
      label: "Открыть в Pyrus ↗"
  labels:
    Id: ID
    BaseTask: Базовая задача
  copyFields: [Id]
  ratingField: Оценка
  recField: Рекомендация
```

Результат внутри заметки:

```text
┌────────────────────────────────────────────────────────┐
│ Задачи  #task                     @   + подзадача      │  < ссылка на доску, тег, настройки
│ [бэклог] [в работе] [готово]                           │  < чипы статуса, клик меняет
│ Открыть в Pyrus > # /                                  │  < ссылка: открыть, копировать, правка
│ * 8                                                    │  < ratingField
│ ID: 4812 #                                             │  < поле с подписью и копированием
│ Базовая задача: Релиз 1.2 /                            │  < викилинк кликабелен
│ Описание текстом.                                      │  < абзац (клик — правка)
│ | Рекомендация курсивом                                │  < recField, акцентная полоса
│ ┌ Дочерние задачи ─────────────────────────── 1/3 ┐    │
│ │ Починить форму входа             [в работе]     │    │
│ │ Починить обновление токена       [готово]       │    │
│ └─────────────────────────────────────────────────┘    │
│ @ поля карточки                                        │
└────────────────────────────────────────────────────────┘
```

- Пустые поля показывают заглушку `+ имя поля`; клик — заполнить.
- Всё редактируется кликом: Enter или потеря фокуса сохраняют, Escape отменяет.
- **Дочерние задачи** появляются только если другие карточки ссылаются на эту через `baseTaskField`.

## Шаблон карточки

В шаблоне — только frontmatter и два пустых блока, раскладка берётся из доски:

````markdown
---
Статус: бэклог
Id:
Описание:
---
#task

```card
```

```tags
```
````

Новая заметка из него открывается как карточка выше. Блок ` ```tags ` добавляет под ней редактор словаря:

```text
┌────────────────────────────────────────────────────────┐
│ словарь: Задачи - по тегу #task                        │
│ Метки   [bug] [feature]                                │
└────────────────────────────────────────────────────────┘
```

## Настройки доски (⚙)

```text
┌─ Настройки доски ──────────────────────────────────┐
│ Папка     [Tasks                               ]   │
│ Шаблон    [Templates/Task.md] [+ создать заметку]  │
│ Колонки   [бэклог     ] ^ v x                      │
│           [в работе    ] ^ v x   [+ добавить]      │
│ Метки     [bug        ] ^ v x                      │
│ Карточка  Поля, Ссылки, Подписи, Копируемые поля   │
│ [Сохранить] [Отмена]  [+ создать новую доску]      │
└────────────────────────────────────────────────────┘
```
