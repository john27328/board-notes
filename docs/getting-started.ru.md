# Быстрый старт

*(English version: [getting-started.md](getting-started.md))*

## 1. Установка

См. [Установка](../README.ru.md#установка): вручную, через BRAT или (позже) из каталога плагинов. Включи **Board Notes** в **Настройки → Сторонние плагины**.

## 2. Пометь заметки тегом

Карточка — любая заметка с тегом доски. Добавь статус во frontmatter:

```yaml
---
Статус: читаю
---
#book
```

## 3. Создай доску

Либо запусти команду **Board Notes: Создать новую доску** (мастер: название, тег, папка, шаблон, колонки), либо вставь блок в любую заметку вручную:

````markdown
```board
tag: "#book"
folder: Books
columns:
  - хочу прочитать
  - читаю
  - прочитано
```
````

Обязателен только `tag`. Без `columns` колонки выводятся из используемых значений статуса.

## 4. Работай с доской

- Перетащи карточку в другую колонку — меняется только её статус.
- Кнопка **Таблица** в тулбаре переключает на редактируемую таблицу (двойной клик по ячейке).
- Поиск и чипы фильтров сужают выдачу; клик по названию ряда фильтра переключает его в режим исключения.
- **⚙** открывает настройки доски: папка, шаблон, колонки, словарь, вид карточки. Переименование колонки или значения словаря обновляет все карточки.
- **+ добавить** в колонке создаёт карточку из `template` со статусом этой колонки.

## 5. Добавь вид карточки в заметки

Вставь пустой блок ` ```card ` (обычно в шаблон). Раскладка берётся из `card:` в конфиге доски; поля редактируются кликом, а ряд чипов статуса позволяет сменить статус, не заходя на доску. Блок ` ```tags ` добавляет редактор словаря.
